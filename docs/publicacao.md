# Publicação

## GitHub

Branch publicada: `main`. Versionar código, dependências, tabela processada e documentação. Não versionar dados brutos, textos livres de avaliações, credenciais, caches ou ambientes virtuais.

Revisar o diff, executar testes e selecionar os arquivos antes de criar commit. Usar [IA] quando houver assistência e preservar atribuições reais.

## Streamlit Community Cloud

O painel usa `app.py`, Python 3.11, `requirements.txt` na raiz e a tabela processada versionada. Não executar download nem pipeline durante a inicialização.

As coordenadas do repositório existente foram mantidas para preservar a administração da aplicação. Alterações de proprietário, nome, branch ou entrada exigem o procedimento de republicação documentado pelo Streamlit.

Após mudanças, conferir as quatro páginas e os filtros em uma sessão anônima. O endereço publicado está no README. A resposta HTTP isolada não confirma o funcionamento de todos os filtros e gráficos.

## Relatórios e revisão

O gerador utiliza os textos e evidências versionados. Revisar o PDF após regenerar; a geração automática não substitui a avaliação dos dados nem a validação humana das conclusões. A origem das respostas e dos complementos permanece em uso_de_ia.md.
